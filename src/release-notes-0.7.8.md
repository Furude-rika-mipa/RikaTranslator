# Rika Translator 0.7.8

- 新增自动预读：能够安全读取后续剧本时，当前句完成后在后台批量翻译后 3 句，结果逐句缓存；无法可靠预读时继续逐句实时翻译。
- 支持已适配的 Flower Knight Girl Viewer 线性剧本和标准 RPG Maker MV/MZ 对话事件。遇到选择、跳转、条件、脚本执行、变量修改或未知结构时停止预读，不自动推进剧情。
- 当前句优先排队，能够复用正在进行的预读请求；批量分句或格式校验失败时，当前句自动退回单句翻译。
- 在“AI 翻译 → 翻译配置”增加预读开关，默认启用。关闭后保持实时翻译；少量预读可能产生未播放台词的 API 用量。
- 服务、语言、提示词、词表、人工译文或翻译开关改变后，使网页适配缓存失效，避免继续使用旧配置的预读结果。
- 保留 0.7.7 的 GitHub 在线更新及发布页按钮修复，默认不备份旧程序，保留完整个人 data。

已安装旧版 Viewer 或 RPG Maker 适配的用户，需要先保存游戏进度并关闭游戏，在新版工具中卸载旧适配、重新安装后，再启动游戏使用预读。其他引擎和未匹配的剧本继续使用原有实时取词。

这是独立的 0.7.8 完整程序包，不修改现有 0.7.7 安装。发布时使用 v0.7.8 标签，上传 RikaTranslator-0.7.8-win-x64.zip 与 SHA256SUMS.txt，并一并提供对应源码包。已使用 0.7.7 的用户可以通过“设置 → 程序更新”下载安装。
