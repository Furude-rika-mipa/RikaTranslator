# Rika Translator 0.7.6

## 新增

- Flower Knight Girl Viewer 常用菜单、按钮、搜索标签、设置、提示、操作说明和部分动态状态支持中文显示。
- 固定界面词条在本机转换，不额外请求翻译 API；目标语言为中文且翻译已启用时生效，暂停后恢复原界面文字。
- 保留按钮事件、快捷键、搜索输入和数值设置；跟随菜单打开和界面更新应用。
- 包含 0.7.5 新增的 Viewer 逐句实时对白翻译、缓存、快进防护、切场景重新绑定和失败恢复。

角色名、剧情选项、自动补全结果、编辑框、图片文字及其他 NW.js 布局暂未接入。未收录的 UI 文字继续显示原文。
剧情对白仍由你配置的服务翻译，费用与数据处理取决于该服务。

## 升级与安装

关闭工具与游戏，先备份完整 data，更新程序文件时保留原 data 和其中的适配器备份。
已安装 0.7.5 Viewer 适配时，先关闭 Viewer 并卸载旧适配；升级后重新检测、安装，再启动 Viewer。
首次使用时添加 Viewer 的 EXE，确认识别为 NW.js 后安装适配。无需开启 Copy Text。
本版本提供完整程序目录；上游 API Key、个人设置、游戏库、存档、测试截图和测试记录不随分发提供。
