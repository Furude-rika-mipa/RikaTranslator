# Rika Translator 0.7.5

- 新增 Flower Knight Girl Viewer 的 NW.js 逐句实时对白翻译，在原对白位置异步显示译文。
- 支持重复句缓存、快进过期响应防护、切场景重新绑定、暂停恢复和服务失败重试。
- 安装备份入口 HTML，并添加一个本机桥接脚本；剧情脚本保持原样，卸载按清单恢复。
- 游戏只保存本机连接凭据，不保存上游 API Key。其他 NW.js 布局暂不开放同等适配。

关闭 Viewer，添加或重新检测其 EXE，确认识别为 NW.js 后安装适配，再启动 Viewer。无需开启 Copy Text。
0.7.5 主要适配对白；菜单与设置的本地中文显示由 0.7.6 新增。
