# 构建 Rika Translator 0.7.8

## 主程序、更新器和 Hook Worker

准备 Windows x64、.NET 10 SDK，以及首次还原 NuGet 依赖所需的网络。
在仓库根目录执行：

```powershell
.\src\build.ps1 -Version '0.7.8' -LooseHookSource -OutputDirectory '.\out\RikaTranslator-0.7.8-win-x64'
```

输出目录必须为空。依赖已经还原时可以加 `-NoRestore`。
脚本构建主程序、独立更新器和 Hook Worker，生成运行目录启动器，复制适配器、许可证及对应源码。
源码中的 `lib/AssetsTools.NET.dll` 及 `adapters/packages` 是构建或适配所需的固定组件，请保留。
构建不会复制内部验证目录或测试记录；输出不包含个人 `data`。

## 原生 LunaHook

随附成品已使用 `12.0.1-rika-fontfix1`。如需修改原生代码，构建说明见：

`src/licenses/galgame/RikaLunaHook-fontfix/README.md`

原始源码包、修复文件、差异、MinHook 源码和构建脚本已随仓库提供。
重新构建后，需同步 DLL、大小、SHA-256 和组件校验清单。

## 分发

完整成品应保留运行库、网页、适配器、许可证、对应源码及构建说明。
主程序对应源码位于本仓库 `src`。将源码版本与成品版本一同标记，确保接收者能取得对应版本源码。
完整成品目录与专用更新 ZIP 是不同分发形式，专用更新 ZIP 由 `create-update-package.ps1` 制作。

## 在线更新发布格式

正式版本使用 `vX.Y.Z` 标签，发布完整程序包 `RikaTranslator-X.Y.Z-win-x64.zip`，
ZIP 最外层目录也为 `RikaTranslator-X.Y.Z-win-x64`。同一 Release 附 `SHA256SUMS.txt`，
其中以“SHA-256、两个空格、文件名”的格式记录完整 ZIP 的摘要。
程序检查最新正式 Release；草稿、预发布和 GitHub 自动生成的 Source code ZIP 不作为在线更新包。
完整包必须保留运行组件、许可证与对应源码，不包含任何个人 `data`。
