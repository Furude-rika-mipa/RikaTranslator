# Rika Translator 0.9.0

本版增加剧本翻译与独立汉化补丁制作，并保留原有实时翻译功能。

- 提取受支持的 KiriKiri / Hxv4、WillPlus / AdvHD、YU-RIS、ExHIBIT、Escu:de、SiglusEngine 和 BGI / Ethornell 剧本；支持选择对白、当前剧本或全部待译。
- 使用已有 AI 服务批量翻译；可启用多服务分担，按服务设置并发，失败时尝试其他可用服务，保存进度并继续未完成内容。
- 支持本地 stdio MCP 外部助手翻译已授权范围；可设置每批最多 1–50 条，默认 8 条。需保持梨花运行。
- 将已完成译文回填到资源副本，生成可独立使用的汉化补丁；未译对白保留原文。可选择系统字体或本机字体文件。
- 已生成补丁可在梨花中打开或确认删除；删除不会移除已保存的译文和其他位置的补丁副本。
- 修复本地服务地址大小写导致部分安装无法打开的问题。

引擎支持针对已适配的具体资源格式，不能保证同一引擎的所有游戏均适用。BGI 游戏副本已验证中文显示；其他新增引擎已验证资源回填，实际游戏内排版及完整流程仍需逐项确认。

从 0.7.7 或更新版本可在“设置 → 程序更新”下载并安装。完整 ZIP 不包含个人设置、API Key、游戏库或译文；更新时保留原有 `data` 目录。
