# Rika Translator 0.8.1

- 游戏详情新增“清理残留”：先扫描组件与备份，列出移除、恢复和保留的内容；确认后恢复原文件并移除内容一致的本工具残留。正常安装应先卸载，发现外部修改、路径不符或原始备份损坏时暂停清理。
- Unity 运行期配置和 Ren’Py 编译缓存会先完整归档，再清理对应残留。
- 旧的原始文件备份默认保留；恢复完成后可单独勾选删除。未归属的组件、存档、译文、导入字体和运行期归档保留。

- 游戏详情的“引擎识别”卡片显示引擎名称和版本号，未识别版本时显示“版本未知”。
- 修复 Unity 6 的 6000.x 版本号无法识别的问题，保留旧版 Unity 及带 c1 等后缀的版本识别。
- 字体制作页选择缺少版本记录的游戏时重新检测，更新后自动选择对应系列模板；显示游戏真实版本和模板真实版本。
- 字体制作页右侧增加“打开字体文件夹”，直接打开已生成字体包及制作报告的保存目录。
- 游戏库的卡片和列表增加“移除”按钮，无需进入详情；确认后只移出游戏库，保留游戏文件、存档、字体和译文。已安装本工具适配的游戏须先卸载或恢复适配。
- 去掉游戏库、译文编辑器、词表和日志搜索框的放大镜图标，恢复文字左侧的正常留白。

包含 0.8.0 的 TTF/OTF 制作静态 SDF TMP 字体包、可调预读句数、全部断开 Hook 及已下载更新保留功能。
Unity 6 结构模板实际来自 6000.4.0f1；识别到游戏为 6000.0.34f1 不代表该字体模板已通过此游戏兼容验证，游戏显示仍需实测。

普通用户下载 RikaTranslator-0.8.1-win-x64.zip，完整解压后运行 RikaTranslator.exe。
发布正式 v0.8.1 Release 并上传程序 ZIP 与 SHA256SUMS.txt 后，支持在线更新的旧版本可通过“设置 → 程序更新”下载安装。更新保留完整个人 data，默认不备份旧程序，不自动更新游戏中的适配。
对应源码为 RikaTranslator-0.8.1-source.zip。第三方许可证和对应源码保留。发布内容不含个人配置、API Key、测试截图或测试记录。
