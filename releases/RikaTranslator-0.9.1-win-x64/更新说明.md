# Rika Translator 0.9.1

- 更新淡紫色界面，调整剧本翻译页面布局和功能说明。
- 剧本翻译可筛选失败对白，跨页勾选筛选范围内的失败项；手动选择上限提高到 1000 条。
- 单 API 和多 API 剧本翻译可设置每批最多 1–50 条，默认 8 条；长对白、场景和总字数限制可能使实际批次更小。批次越大，可能越容易超时或出现格式错误。
- 新增译文检查，可查看控制符差异、失败项和可能过长的对白；支持查找原文与译文完全相同的条目、定位对白和手动修订。检查不自动修改译文、不调用 AI；长句仅作提示，原译文相同也可能是正常情况。
- 显示更清楚的任务进度与失败原因，并在游戏详情提供诊断建议和剧本资源兼容情况。引擎识别与实际游戏适配仍需分别验证。
- 改进 KiriKiri / Hxv4 补丁对译文换行的处理，新生成的补丁不再附带 `patch-map.txt`。

0.7.7 及更新版本可在“设置 → 程序更新”下载并安装。完整程序 ZIP 不包含个人设置、API Key、游戏库或译文；更新保留本地 `data` 目录。已生成的旧补丁不会被修改；修订译文后需重新生成补丁。
