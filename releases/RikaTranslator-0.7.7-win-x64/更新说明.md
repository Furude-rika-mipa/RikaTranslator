# Rika Translator 0.7.7

- 新增 GitHub 在线检查、版本说明、下载进度、取消下载，以及校验后安装并重启。
- 修复桌面窗口点击“查看发布页”没有反应，改为通过系统默认浏览器打开 GitHub 发布页。
- 识别当前 Release 的完整 Windows x64 程序 ZIP；校验下载大小、SHA-256、目录和启动组件后再交给独立更新器安装。
- GitHub 匿名 API 限流时尝试公开发布页和校验文件，无需 GitHub 登录，不使用翻译服务的 API Key。
- 默认不备份旧程序，保留个人 data，包括密钥、游戏库、字体、译文和适配器原始备份。
- 不备份模式下，安装中断或启动检查失败会明确提示用完整程序包修复，不显示已回滚。成功重启后清理本次更新的临时文件。
- 旧更新任务的备份恢复行为保留；仍可导入专用本地更新 ZIP。

首次从 0.7.6 或更早版本升级，需要先安装一次含在线更新功能的完整新版程序。后续在设置 → 程序更新检查和下载。
